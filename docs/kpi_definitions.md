# KPI Definitions

## Dashboard 1: Executive Championship Overview
- Cumulative championship points per driver, per season (line chart, race-by-race)
- Wins and podiums per constructor per season (bar chart)
- Current season leader, points gap to 2nd place (headline numbers)

## Dashboard 2: Constructor Reliability Deep-Dive
- Mechanical failure rate per constructor per season (heatmap)
- Finish rate per constructor per season
- Accident rate per constructor per season

## Dashboard 3: Qualifying vs Race Pace
- Grid position vs finish position (scatter plot, per driver)
- Grid delta distribution per driver (box plot)
- Teammate head-to-head record (per constructor, per season)
